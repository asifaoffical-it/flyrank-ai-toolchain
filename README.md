# flyrank-ai-toolchain

My FlyRank AI internship setup and portfolio project.

## FE-01 Setup

This repository is currently used for environment setup and AI-assisted development practice during the FlyRank internship. It is not used for application development at this stage.

The following tools are required:

* **Node.js (LTS)** — JavaScript runtime for running and managing project scripts.

* **Git** — version control.
* **GitHub** — remote hosting and collaboration.
* **Cursor** — AI-assisted code editor used for development practice.

Complete local setup of these tools before continuing with later internship work.
